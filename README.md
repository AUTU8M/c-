# C++ Practice Hub

This repository is a practice hub for **C++**, focused mainly on:

- **DSA (Data Structures & Algorithms)**
- **Patterns**

## Structure

```text
.
├── dsa/
│   └── arrays/
│       └── two_sum.cpp
└── patterns/
    └── basic/
        └── half_pyramid.cpp
```

## How to Run

Compile and run any file with `g++`:

```bash
g++ dsa/arrays/two_sum.cpp -std=c++17 -O2 -Wall -Wextra -pedantic -o two_sum
./two_sum

g++ patterns/basic/half_pyramid.cpp -std=c++17 -O2 -Wall -Wextra -pedantic -o half_pyramid
./half_pyramid
```

## Goal

Use this repo to regularly practice C++ problem-solving with small, focused examples.
